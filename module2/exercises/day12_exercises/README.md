

# Day 12 HTML Exercises 🌐

This is my **Day 12 HTML practice project**. I created this project to practice HTML forms, tables, images, maps, and accessibility.

## What I Used

* HTML5
* Forms
* Tables
* Images
* Google Maps iframe
* HTML accessibility features

## What the Page Includes

### 1. Ethio Telecom Registration Form

The form includes:

* Full name
* Email
* Phone number
* Branch selection
* Register button

The phone number is also checked using an HTML pattern for the Ethiopian `+251` format.

### 2. Ethiopian Airlines Flight Table

A flight schedule table showing:

* Flight number
* Departure city
* Destination
* Departure time
* Price in ETB

### 3. Media Block

The page includes:

* Lalibela image
* Image description
* Another Lalibela image
* Google Maps location

### 4. Accessibility Practice

I practiced making the page more accessible by using:

* Proper buttons
* Labels for form inputs
* Alternative text for images
* Semantic HTML elements

4. You can also use Live Server in VS Code.
