

# CSS Reading Sheet - Module 2 Day 13 🎨

This is a CSS practice project I created for **Module 2, Day 13**.

The project contains different examples that helped me understand important CSS concepts such as custom properties, the box model, specificity, tables, and colors.

## What I Used

* HTML
* CSS
* CSS Custom Properties
* Box Model
* CSS Specificity
* Tables
* RGB and HSL colors
* Hover effects

## What the Page Includes

### 1. Custom Properties & Button

A simple button using CSS custom properties to practice reusable values.

### 2. Box Model

Shows the difference between:

* `content-box`
* `border-box`

It also demonstrates how padding and borders affect the final width of an element.

### 3. CSS Specificity

Shows how different selectors are compared:

* Element selector
* Class selector
* ID selector

The example shows why the ID selector has the highest specificity.

### 4. Ethiopian Airlines Schedule

A simple flight schedule table showing:

* Flight number
* Route
* Departure
* Arrival
* Gate

### 5. Color Palette

Three buttons demonstrate different colors and hover effects using CSS color values.
