3. Specificity Demo

Three rules all target the same paragraph. Only one color wins — the browser decides using specificity, not source order.

Selector Rule Specificity (ID-Class-Element)
p color: blue; 0-0-1
.note color: green; 0-1-0
#warning color: red; 1-0-0 ← wins

I am targeted by all three rules above — and I render red.

Why red? Specificity is compared left to right as a tuple. Any ID (1-0-0) outranks any number of classes, and any class (0-1-0) outranks any number of element selectors (0-0-1). So #warning wins outright — source order never even comes into play here.
