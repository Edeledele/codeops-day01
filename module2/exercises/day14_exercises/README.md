# Yohannes Coffee House ☕

This is a simple coffee house webpage that I created as a **layout practice project**.

The project helped me practice creating a page with a navigation bar, sidebar, menu cards, a photo gallery, and a footer using HTML and CSS.

## What I Used

* HTML
* CSS
* Flexbox
* Images

## What the Page Includes

* Coffee house logo and name
* Navigation sidebar
* Coffee menu
* Menu cards with prices
* Order buttons
* Short description about the coffee house
* Coffee photo gallery
* Footer

## Menu

The page includes:

* ☕ Macchiato — 95 ETB
* ☕ Coffee Ceremony — 150 ETB
* 🧊 Iced Cold Brew — 110 ETB

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. You can also use Live Server in VS Code.
