

# Nevi Cake Menu 🍰

This is a simple and responsive **cake menu webpage** that I created as an HTML and CSS practice project.

The page displays different cakes with their images, descriptions, and prices in Ethiopian Birr (ETB).

## What I Used

* HTML
* CSS
* CSS Grid
* CSS Media Queries
* CSS Transitions
* Responsive Design

## What the Page Includes

The menu has different types of cakes, including:

* 🍫 Chocolate Fudge Cake
* 🎂 Vanilla Birthday Cake
* ❤️ Red Velvet Cake
* 🥕 Carrot Cake
* 🍒 Black Forest Cake
* 💍 Tiered Wedding Cake
* 🍋 Lemon Drizzle Cake
* 🍍 Pineapple Cake
* 🧀 Baked Cheesecake
* 🍰 Marble Cake

Each cake has:

* An image
* Name
* Short description
* Price

## Responsive Design

The page is designed to work on different screen sizes.

* **Mobile:** One column
* **Tablet:** Two columns
* **Desktop:** Three columns

The cards also have a small hover animation to make the page more interactive.

The project includes a **reduced-motion option** for users who prefer less animation.

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. You can also use **Live Server** in VS Code.
