# Day 18 - JavaScript Array Methods, Objects & Modules 🚀

This is my **Day 18 JavaScript practice project**. In this project, I practiced array methods, objects, destructuring, spread syntax, functions, and JavaScript modules using Node.js.

## What I Used

- JavaScript
- Node.js
- `map()`
- `filter()`
- `reduce()`
- `for...of`
- `Object.entries()`
- Object destructuring
- Parameter destructuring
- Spread syntax
- Functions
- JavaScript modules
- `require()`
- `module.exports`

## What the Project Includes

### Exercise 1: map / filter / reduce

I practiced using JavaScript array methods with Ethiopian Birr (ETB) prices.

- Used `map()` to add 15% VAT
- Used `filter()` to find prices below 1000 ETB
- Used `reduce()` to calculate the grand total
- Used a helper function to round values to 2 decimal places

### Exercise 2: Object.entries + for...of

I practiced working with JavaScript objects.

The customer object contains:

- Name
- City
- Balance

I used `Object.entries()` with a `for...of` loop to display the object's key-value pairs.

### Exercise 3: Destructuring

I practiced:

- Object destructuring
- Function parameter destructuring

The customer's name and city are extracted directly from the object.

### Exercise 4: Spread Syntax

I practiced using the spread operator to create an updated copy of an object without changing the original object.

The updated customer includes:

- New city
- Phone number

The original customer object remains unchanged.

### Exercise 5: JavaScript Modules

I created a separate `money.js` module for money-related functions.

The module includes:

- VAT constant
- `addVat()` function

The `app.js` file imports these using:

```javascript
require("./money.js")
