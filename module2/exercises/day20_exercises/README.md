# Day 20 — Async/Await, Error Handling & Promise.all

## 📚 Overview

Day 20 focuses on asynchronous JavaScript and working with APIs using:

- `fetch()`
- Promises
- `async/await`
- `try/catch`
- HTTP error handling
- `Promise.all()`
- Loading and error states

The exercises demonstrate how JavaScript can request data from APIs and handle both successful and failed requests.
