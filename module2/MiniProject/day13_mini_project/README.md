

# Yohannes Buna Bet ☕

This is a simple webpage for **Yohannes Buna Bet**, a coffee shop located in Bole, Addis Ababa.

I created this project as a small HTML and CSS practice project. The page shows basic information about the coffee shop in a simple and clean way.

## What I Used

* HTML
* CSS
* Google Fonts

## What the Page Includes

* Coffee shop name
* Open status
* Short description
* Address
* Opening hours
* Phone number
* Reservation information
* Contact button

## Project Files

```text
day13_mini_project/
│
├── index.html
├── styles.css
└── README.md
```

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. You can also use Live Server in VS Code.

## About the Project

This is a **practice project for learning HTML and CSS**. The coffee shop information used on the page is for demonstration purposes.
