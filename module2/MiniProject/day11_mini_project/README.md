
# Habesha Market 🛍️

This is a simple webpage for **Habesha Market**, a fictional Ethiopian online marketplace.

I created this project to practice the basics of HTML, including headings, links, images, lists, sections, and a footer.

## What I Used

* HTML
* Images
* Basic HTML links and formatting

## What the Page Includes

* Habesha Market homepage
* Navigation links
* Ethiopian products section
* Coffee product image
* Product list
* About section
* Checkout steps
* Contact page link
* Ethiopian Airlines partner link

## Products

The website includes some Ethiopian products such as:

* ☕ Coffee
* 🌾 Teff
* 🧣 Handwoven cotton scarves

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. You can also use Live Server in VS Code.

## About the Project

Habesha Market is a **fictional project created for learning purposes**. It is designed to show how an Ethiopian marketplace website could be structured using basic HTML.
