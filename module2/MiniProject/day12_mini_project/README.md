
# Habesha Eatery 🍽️

This is a simple restaurant reservation webpage for **Habesha Eatery** in Bole, Addis Ababa.

I created this project to practice HTML forms, tables, navigation, and basic accessibility. The page allows customers to request a table and also see some traditional Ethiopian dishes and their prices.

## What I Used

* HTML
* CSS
* Google Fonts

## What the Page Includes

* Restaurant information
* Table reservation form
* Customer name and email
* Phone number
* Number of guests
* Date and time selection
* Special requests
* Ethiopian food menu
* Food prices in ETB
* Traditional Ethiopian coffee ceremony section
* Contact information
* Navigation links

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. You can also use Live Server in VS Code.

## About the Project

This is a **practice project for learning HTML and CSS**. The restaurant information, menu, prices, and reservation details are for demonstration purposes.
