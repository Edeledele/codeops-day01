

# Ethio-Telecom Account Dashboard

This is a simple **Ethio-Telecom account dashboard** that I created as a coursework project.

The main idea of this project is to create a dashboard where a customer can easily see their account information, data usage, balance, services, and recent activities.

## What I Used

* HTML
* CSS
* Google Fonts

## Features

The dashboard includes:

* Customer profile
* Data remaining
* Voice minutes
* SMS remaining
* Current balance
* Recharge button
* Data bundles
* SIM services
* Family lines
* Billing
* Roaming
* Support tickets
* Recent account activity

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. You can also use VS Code with Live Server.

## About the Project

This project is only a **front-end design for learning purposes**. The information shown on the dashboard is not real, and the buttons and links are not connected to a real Ethio-Telecom system.
