Signup Form

A simple signup form that collects a user's name and Ethiopian phone number.

Features
Validates name and phone number
Supports Ethiopian numbers like 0912345678 and +251912345678
Saves signups in localStorage
Prevents duplicate phone numbers
Allows saved signups to be removed
Files
index.html
style.css
app.js

How to Run
Put all three files in the same folder.
Open index.html in your browser.
Enter a name and Ethiopian phone number.
Click Sign up.

Saved signups will remain after refreshing the page.
