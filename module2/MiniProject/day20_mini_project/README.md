# 🌍 Country Facts

A simple single-page web application that allows users to search for a country and view important information about it using live data from the REST Countries API.

The application displays:

- 🏛️ Capital
- 👥 Population
- 🌎 Region
- 💰 Currencies
- 🚩 Country flag

---

## 📚 Overview

This project was created to practice working with:

- JavaScript `fetch()`
- REST APIs
- `async/await`
- Error handling
- DOM manipulation
- `createElement()`
- `textContent`
- Form events
- Loading and error states
- JSON data

The application starts with **Ethiopia** displayed by default.

---
