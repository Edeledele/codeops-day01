# Day 5 - Python Inheritance, Polymorphism & Abstraction 🐍

This is my **Day 5 Python practice project**. In this project, I practiced inheritance, polymorphism, abstraction, and building a simple account hierarchy.

The exercises are divided into three levels.

## What I Used

* Python
* Inheritance
* `super()`
* Polymorphism
* Abstraction
* Abstract classes
* `ABC`
* `abstractmethod`
* Method overriding
* Observer pattern

## Level 1 - Inheritance Basics

In Level 1, I practiced:

* Creating a parent `Vehicle` class
* Creating `Car` and `Motorcycle` child classes
* Using inheritance with `super()`
* Creating an `Account` class
* Creating `SavingsAccount` and `CurrentAccount`
* Adding interest to savings
* Using an overdraft limit

## Level 2 - Polymorphism & Abstraction

In Level 2, I practiced:

* Creating an abstract `Account` class
* Using `ABC` and `abstractmethod`
* Creating different account types
* Overriding methods
* Calculating interest differently for each account
* Using polymorphism with a list of accounts

## Level 3 - Full Account Hierarchy

In Level 3, I practiced:

* Creating a complete account hierarchy
* Using private/protected balance
* Using properties
* Creating savings and current accounts
* Applying interest
* Handling overdrafts
* Using abstract methods

## Advanced Account System

The project also includes:

* Bank configuration
* SMS withdrawal alerts
* Audit logs
* Observer pattern
* Large withdrawal notifications
* Savings interest calculation
* Account statements
