In this exercise, I practiced:

* Inserting accounts
* Searching for accounts

## Tree

In the Tree exercise, I practiced:

## Graph

In the Graph exercise, I practiced:

* Creating a customer transfer graph
* Adding customers
* Adding connections between customers
* Using Breadth-First Search (BFS)
* Using Depth-First Search (DFS)

## Heap

In the Heap exercise, I practiced:

* Creating a transaction heap
* Adding transactions
* Assigning priorities
* Processing the highest-priority transaction
* Using Python's `heapq` module
