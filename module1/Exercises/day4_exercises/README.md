

# Day 4 - Python Classes & Objects 🐍

This is my **Day 4 Python practice project**. In this project, I practiced working with classes, objects, methods, properties, and encapsulation.

The exercises are divided into three levels.

## What I Used

* Python
* Classes
* Objects
* Constructors
* Methods
* Properties
* Encapsulation
* Private variables
* Object interaction

## Level 1 - Basic Classes

In Level 1, I practiced:

* Creating classes and objects
* Using constructors
* Creating object attributes
* Creating methods
* Calculating rectangle area and perimeter
* Creating a basic bank account
* Depositing and withdrawing money

## Level 2 - Intermediate Classes

In Level 2, I practiced:

* Creating a Student class
* Adding and calculating grades
* Creating a Product class
* Managing product stock
* Using encapsulation
* Protecting account balance using private variables

## Level 3 - Advanced Classes

In Level 3, I practiced:

* Creating a full BankAccount class
* Depositing and withdrawing money
* Transferring money between accounts
* Creating a simple Library system
* Borrowing and returning books
* Creating a Car class
* Managing speed and fuel

## Encapsulated Bank Account

The project also includes a simple encapsulated bank account that can:

* Create an account
* Deposit money
* Withdraw money
* Check the account balance
