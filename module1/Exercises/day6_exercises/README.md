
# Day 6 - SOLID Principles & Design Patterns 🐍

This is my **Day 6 Python practice project**. In this project, I practiced SOLID principles and common design patterns using Python.

The exercises are divided into three levels.

## What I Used

* Python
* SOLID Principles
* Single Responsibility Principle
* Open/Closed Principle
* Liskov Substitution Principle
* Interface Segregation
* Dependency Inversion
* Singleton Pattern
* Factory Pattern
* Observer Pattern
* Abstract Classes

## Basic Exercises - SOLID Principles

In the Basic exercises, I practiced:

* Single Responsibility Principle
* Open/Closed Principle
* Liskov Substitution Principle
* Identifying SOLID violations
* Separating different responsibilities
* Using inheritance correctly

## Intermediate - Design Patterns

In the Intermediate exercises, I practiced:

* Separating database and notification responsibilities
* Factory Pattern
* Observer Pattern
* Interface Segregation
* Creating different account types
* Sending notifications for large withdrawals

## Advanced - SOLID & Design Patterns

In the Advanced exercise, I practiced:

* Singleton Pattern for bank configuration
* Factory Pattern for creating accounts
* Observer Pattern for SMS alerts and audit logs
* Abstract account classes
* Savings and current accounts
* Deposit and withdrawal operations
* Interest calculation
* Large withdrawal notifications
