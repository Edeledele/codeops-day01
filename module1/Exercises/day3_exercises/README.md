

# Day 3 - Python Collections, Files & Error Handling 🐍

This is my **Day 3 Python practice project**. In this project, I practiced working with different Python collections, files, modules, and error handling.

The exercises are divided into three levels.

## What I Used

* Python
* Lists
* Tuples
* Dictionaries
* Sets
* List comprehension
* Modules
* File reading and writing
* Exception handling
* `try`, `except`, and `finally`

## Level 1 - Collections

In Level 1, I practiced:

* Creating and changing lists
* Adding and removing items
* Using tuples
* Unpacking tuples
* Creating dictionaries
* Adding and updating dictionary values
* Removing duplicate values using sets

## Level 2 - Intermediate Collections

In Level 2, I practiced:

* Finding numbers using conditions
* Sorting lists
* Calculating sum and average
* Working with dictionaries
* Searching for dictionary values
* List comprehension
* Creating even and odd number lists
* Importing functions from another Python file

## Level 3 - Files & Error Handling

In Level 3, I practiced:

* Creating a text file
* Writing student information to a file
* Reading information from a file
* Calculating an average from file data
* Handling errors
* Using `try`, `except`, and `finally`

## Inventory Manager

The project also includes a simple inventory manager that can:

* Add or update inventory items
* View inventory
* Exit the program
