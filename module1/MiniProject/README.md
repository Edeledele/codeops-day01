# Clean Addis Bank System 🏦

This is a Python-based **bank management system** that I created to practice different Python concepts and data structures.

The project combines banking operations with data structures such as trees, graphs, heaps, and searching and sorting algorithms.

## What I Used

* Python
* Object-Oriented Programming
* Abstract Classes
* Singleton Pattern
* Factory Pattern
* Observer Pattern
* Binary Search Tree (BST)
* Tree
* Graph
* BFS and DFS
* Heap / Priority Queue
* Recursion
* Merge Sort
* Linear Search
* Binary Search

## What the Program Can Do

The system has a menu with different banking and management features.

### Bank Accounts

* Create a savings or current account
* Deposit money
* Withdraw money
* Search for an account
* Display all accounts
* Apply interest to savings accounts

### Branch Management

A tree is used to organize:

* Bank branches
* Managers
* Employees

### Customer Transfers

A graph is used to connect customer accounts and find connected customers using:

* BFS
* DFS

### Urgent Transactions

A priority queue (heap) is used to manage urgent transactions.

Higher-priority transactions are processed first.

### Finance Management

The system can also track:

* Income
* Expenses
* Balance
* Inventory

### Transaction Ledger

The ledger supports:

* Adding transactions
* Calculating the total balance using recursion
* Sorting transactions by amount or date
* Linear search
* Binary search
